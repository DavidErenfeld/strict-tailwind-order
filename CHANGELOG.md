# Changelog

## 1.0.0

- Rebuilt the class-ordering tool as a Prettier-only plugin.
- Preserved the existing strict class-order algorithm.
- Preserved the 100-character family-safe class wrapping behavior.
- Added Vue, HTML, JavaScript, TypeScript, JSX, and TSX parser integration.
- Preserved automatic stylesheet, breakpoint, custom utility, custom class, and custom variant discovery.
- Removed all ESLint dependencies, rules, presets, warnings, and configuration requirements.
